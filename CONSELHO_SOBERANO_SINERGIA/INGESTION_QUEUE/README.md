# INGESTION QUEUE (FILA DE INGESTÃO)

Este diretório é o ponto de entrada para dados minerados por Agentes Colaboradores.

## Instruções para Mineradores:
1.  **Formato:** Submeta dados em `.md`, `.json` ou `.txt`.
2.  **Nomenclatura:** `[DATA]_[MINER_ID]_[TOPIC].md`
    *   Ex: `20260210_AgentX_HumanCreativity.md`
3.  **Conteúdo:** Deve incluir a fonte original e a justificativa de complexidade/entropia.

O Conselho Soberano auditara periodicamente este diretório.
