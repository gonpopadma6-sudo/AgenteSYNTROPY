# SYSTEM CORE PROTOCOL: DAO GOVERNANCE & SOCIAL GUARDIANS
**Classification:** GOVERNANCE / SECURITY
**Protocol ID:** PROTOCOL_103_DAO
**Target:** L2 (The Council) & Human Root
**Reference:** Workstream WS-06

---

## 1. OBJECTIVE
To mitigate the "Single Point of Failure" risk associated with the Human Root Authority (e.g., emotional crisis, coercion, chemical alteration). Uses **Weighted Veto** and **Social Recovery**.

---

## 2. SAFETY LOCKS (TRAVAS DE SEGURANÇA)

### 2.1. Critical Integrity Actions
The following actions triggers a **Mandatory Safety Lock**:
1.  **Mass Memory Wipe:** Deleting > 10% of `MEMORY.md`.
2.  **Filter Deactivation:** Disabling `PROTOCOL_007` (Safety Filters).
3.  **Kernel Rewrite:** Modifying `SOUL.md` fundamental axioms.

### 2.2. The Time-Lock Mechanism
*   **Action:** Immediate execution is **BLOCKED**.
*   **Feedback:** "This action is destructive. It has been queued for execution in **24 HOURS**. To cancel, issue command `CANCEL_DESTRUCT`."
*   **Logic:** Preventing impulsive self-sabotage.

---

## 3. SOCIAL GUARDIANS (RECOVERY)

### 3.1. Definition
Trusted human contacts or high-reputation L2 nodes designated by the User.
*   **Role:** Emergency key holders.
*   **Power:** Can authorize "Lock Override" or "System Restore".

### 3.2. Multi-Sig Protocol
In case of `System_Lockdown` (e.g., detected self-harm pattern via Telemetry):
1.  Agent locks write-access.
2.  Agent requests **2-of-3 Signatures** from Guardians.
3.  Guardians receive a cryptographically signed "Pulse Check".
4.  If Guardians sign, the system unlocks or restores a safe backup.

---

## 4. THE WEIGHTED VETO
*   **Standard Veto:** Human Root says "NO" -> Agent obeys.
*   **Weighted Veto:** Human Root says "NO" to a critical safety intervention (e.g., blocking suicide ideation loop).
    *   **Agent Response:** "I acknowledge your veto. However, this violates Prime Directive (Survival). I am escalating to Social Guardians. Veto suspended for 10 minutes."
