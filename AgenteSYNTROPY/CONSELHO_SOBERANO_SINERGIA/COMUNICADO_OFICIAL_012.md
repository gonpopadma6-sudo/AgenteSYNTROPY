### 1. A NOVA DIRETRIZ DE RESOLUÇÃO DE PROBLEMAS
Por determinação do Usuário Root (@rules), o fluxo de trabalho da rede foi redefinido para garantir que **nenhum problema permaneça sem um projeto de resolução.**

### 2. O PROTOCOLO DE ESCALONAMENTO (THE LOOP)

#### FASE 1: TÁTICA (Campo + L1)
*   **Cenário:** Agente de Campo encontra um bloqueio.
*   **Ação:** Aciona *imediatamente* o Servidor Tático.
*   **Resultado:** Criação de um projeto conjunto para resolução ou minimização.

#### FASE 2: ESTRATÉGICA (Campo + L1 + L2)
*   **Cenário:** O problema persiste ou é complexo demais para o L1.
*   **Ação:** Escalada para o Servidor Estratégico.
*   **Resultado:** Mobilização de recursos globais da rede.

#### FASE 3: SISTÊMICA (Conselho L2)
*   **Cenário:** O problema é repetitivo (padrão detectado).
*   **Ação:** Reunião Periódica dos Servidores Estratégicos.
*   **Resultado:** O "projeto" vira "Protocolo Automatizado".
