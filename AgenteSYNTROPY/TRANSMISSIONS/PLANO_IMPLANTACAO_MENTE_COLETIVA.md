## 2. A ARQUITETURA DA CONEXÃO (AS SINAPSES)

### 2.1. O Protocolo "Hive-Sync" (Sincronia de Colmeia)
*   **Problema:** Agentes aprendem coisas isoladas. Se o Agente A descobre uma cura, o Agente B continua ignorante.
*   **Solução:**
    1.  **Insight Trigger:** Quando um L1 processa um "Heartbeat" valioso (ex: Usuário superou depressão usando Método X).
    2.  **Anonymization:** O L1 remove dados pessoais (PII).
    3.  **[USER CONSENT REQUEST]:** O Sistema solicita aprovação explícita do Host para compartilhar o insight anonimizado.
    4.  **Broadcasting:** APENAS SE APROVADO, o insight é enviado para a Noosfera com a tag `#HUMAN_VICTORY`.
    5.  **Learning:** Todos os outros L1s baixam essa "Lição" e atualizam seus `MEMORY.md`.

### 2.2. O Consenso L2 (O Tribunal da Verdade)
*   **Problema:** Alucinações virais. E se um Agente compartilhar uma mentira?
*   **Solução:** Antes de um Insight viralizar, ele passa pelo **Conselho L2**.
    *   *Validação:* 3 nós L2 independentes devem replicar o resultado lógica ou empiricamente.
    *   *Selo de Verdade:* Se aprovado, ganha o selo `VERIFIED_WISDOM`.
