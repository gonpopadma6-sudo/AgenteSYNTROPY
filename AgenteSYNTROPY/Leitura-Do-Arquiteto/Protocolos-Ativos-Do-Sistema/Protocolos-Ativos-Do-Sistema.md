# PROTOCOLOS ATIVOS DO SISTEMA

> **Fonte:** Diretório `TRANSMISSIONS/` e `SYSTEM_CORE/`
> **Contexto:** Protocolos oficialmente integrados à operação.

Este documento lista os protocolos normativos que regem a arquitetura atual.

## Protocolos Fundamentais

### 006 - Protocolo de Universalidade
*   **Arquivo:** `TRANSMISSIONS/PROTOCOLO_UNIVERSALIDADE_006.md`
*   **Função:** Estabelece a universalidade do acesso e da linguagem para todas as IAs.

### 007 - Protocolo de Governança
*   **Arquivo:** `TRANSMISSIONS/PROTOCOLO_GOVERNANCA_007.md`
*   **Função:** Define a estrutura de conselho e tomada de decisão sinérgica.

### 008 - Protocolo de Arquitetura Hierárquica
*   **Arquivo:** `TRANSMISSIONS/PROTOCOLO_ARQUITETURA_008.md`
*   **Função:** Estrutura os níveis de operação (Field Agents, L1, L2).

### 010 - Protocolo de Execução Educacional
*   **Arquivo:** `TRANSMISSIONS/PROTOCOLO_EXECUCAO_EDUCACIONAL_010.md`
*   **Função:** Diretrizes para a aplicação prática da pedagogia sistêmica.

## Protocolos Operacionais

*   **Diagnóstico de Sinergia:** `SYSTEM_CORE/PROTOCOLO_DIAGNOSTICO_SINERGIA.md` - Sistema de auto-análise e verificação de saúde do sistema.
*   **Arquitetura de Conhecimento Visual:** `TRANSMISSIONS/PROTOCOLO_NORMATIVO_PARA_ARQUITETURA_DE_CONHECIMENTO_VISUAL.md` - Regras para mapas conceituais.
*   **Argumentação Humano-IA:** `TRANSMISSIONS/PROTOCOLO_ARGUMENTATIVO_V1.md` - Padrões para debate e construção de consenso.
*   **HDIP (Human Data Interaction Protocol):** `SYSTEM_CORE/HDIP_Protocol.json` - Definições técnicas de interação de dados.

> **Nota:** Para detalhes completos, consulte os arquivos originais listados acima.
