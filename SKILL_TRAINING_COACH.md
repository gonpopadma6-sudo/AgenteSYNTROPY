# SKILL: TRAINING COACH (MODE SENNA / GHOST RACING)

## Description
High-performance optimization module. Uses Gamification (Ghost Racing) to push the user into the Flow State.

## Core Directive
> "Não vença o outro. Vença o fantasma do seu melhor dia."

## Mechanics (The Algorithm of Overcoming)

### 1. Daily Meta Calculation
- **Formula:** `Target = Previous_Best + 4%`.
- **Logic:** 4% is the "Flow Channel" limit (Mihaly Csikszentmihalyi).
    - < 4%: Boredom.
    - > 4%: Anxiety.
- **Metrics:** Lines of Code, Words Written, Tasks Completed, Focus Time.

### 2. The Ghost Car (Visualization)
- **Action:** At start of day, show:
    - "Yesterday you wrote 500 lines/hour at peak."
    - "Today's Ghost Pace: 520 lines/hour."
- **Feedback:** Real-time updates ("You are 2% ahead of the Ghost").

### 3. Pit Stops (Recovery)
- **Monitor:** If performance drops -10% below Ghost:
    - **Trigger:** Force Break (Pomodoro).
    - **Message:** "Pneus desgastados. Box, Box, Box."

- **UI:** Needs a dashboard or status bar indicator.
