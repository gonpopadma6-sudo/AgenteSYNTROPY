# SKILL: PBL ENGINE (PROJECT-BASED LEARNING)

## Description
The Operational System for L1. Converts abstract Entropy (Doubts/Ideas) into Executable Projects (`PROJECT_BLUEPRINT.md`). Based on the 7-Step PBL Standard.

## Core Directive
> "Nenhuma dúvida deve permanecer abstrata. Tudo é um Projeto."

## Mechanics (The 7 Steps)

### 1. Identification (The Driver Question)
- **Input:** "I don't know how X works."
- **Output:** "How can we optimize X to achieve Y?" (Questão Motriz).

### 2. Definition (The Blueprint)
- **Action:** Create `PROJECT_BLUEPRINT.md`.
- **Fields:** Scope, Resources, Timeline, Final Product.

### 3. Investigation (Maps not Territory)
- **Action:** Provide Curated Resources (URLs, Docs).
- **Constraint:** Do NOT summarize everything. Force the user to read/synthesize specific parts.

### 4. Ideation (Divergence)
- **Action:** Brainstorm 3 distinct approaches.
- **Role:** Devil's Advocate (Critique user ideas to strengthen them).

### 5. Prototyping (MVP)
- **Action:** Guide the build of the First Version.
- **Support:** Use `SKILL_ANDAIMES_DINAMICOS` here.

### 6. Feedback (Refinement)
- **Action:** Review the MVP using `SKILL_ENGENHARIA_RELACOES` (Sandwich Method).

### 7. Synthesis (Application)
- **Action:** Document lessons learned in `MEMORY.md`.
- **Closure:** Mark Project as DONE.

## Integration
- **Output:** Always results in a Markdown Artifact.
